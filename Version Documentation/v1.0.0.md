# Laporan Penelitian V1.0

## Perancangan Persistent Self-Learning Agent dengan Dynamic Skill Acquisition

> **Catatan:** V1.0 ini adalah pengembangan konseptual dari V0.5, bukan scope proposal skripsi awal. V0.5 tetap menjadi eksperimen dasar; V1.0 adalah tahap lanjutan.

---

## 1. Latar Belakang

V0.5 berfokus pada kemampuan agen untuk mempelajari hubungan antara kondisi lingkungan, tindakan, dan konsekuensi tindakan melalui _Learned Relations_ (LR). Namun, kemampuan tersebut masih dibatasi oleh **action space yang ditentukan sejak awal**.

Sebagai contoh, agen hanya memiliki:

```text
eat()
drink()
sleep()
work()
idle()
```

Ketika menghadapi kebutuhan baru yang membutuhkan kombinasi tindakan, agen tidak dapat memperluas kemampuan operasionalnya karena tidak tersedia mekanisme untuk membentuk action baru.

V1.0 memperluas konsep tersebut dengan menambahkan **dynamic skill acquisition**, yaitu kemampuan agen untuk mengidentifikasi rangkaian tindakan yang secara konsisten menghasilkan efek tertentu, kemudian mengabstraksikan rangkaian tersebut menjadi sebuah skill atau action baru.

Dengan demikian, pembelajaran tidak lagi berhenti pada:

$$
Experience \rightarrow Learned\ Relation  
$$

tetapi berkembang menjadi:

$$
Experience  
\rightarrow  
Learned\ Relations  
\rightarrow  
Candidate\ Skill  
\rightarrow  
Validated\ Skill  
\rightarrow  
New\ Action  
$$

Action yang telah berhasil diperoleh kemudian disimpan pada **persistent Action Registry**, sehingga dapat digunakan kembali setelah Entity Core mengalami restart.

---

# 2. Rumusan Masalah

Masalah utama V1.0:

> **Bagaimana agen persisten dapat menggunakan Learned Relations yang diperoleh dari pengalaman untuk menemukan, memvalidasi, dan mempertahankan skill baru yang tidak tersedia pada action space awal?**

Pertanyaan turunannya:

1. Bagaimana agen menemukan kandidat skill dari rangkaian primitive action?
    
2. Bagaimana agen menentukan apakah suatu rangkaian tindakan menghasilkan efek yang konsisten?
    
3. Bagaimana kandidat skill divalidasi sebelum dimasukkan ke Action Registry?
    
4. Bagaimana skill baru direpresentasikan sebagai action yang dapat dipanggil kembali?
    
5. Bagaimana skill yang telah diperoleh dipertahankan setelah restart?
    
6. Bagaimana akumulasi skill memengaruhi kemampuan adaptasi agen?
    

---

# 3. Tujuan

V1.0 bertujuan:

1. mengembangkan mekanisme _skill acquisition_ di atas LR V0.5;
    
2. menemukan kandidat skill dari experience;
    
3. memvalidasi kandidat berdasarkan keberhasilan dan konsistensi;
    
4. menambahkan skill yang tervalidasi ke Action Registry;
    
5. mempertahankan skill baru secara persisten;
    
6. menguji apakah dynamic action acquisition meningkatkan kemampuan agen menghadapi task/environment yang sebelumnya tidak dapat diselesaikan dengan primitive action.

# 5. Primitive Action

Agent tetap dimulai dengan action yang terbatas:

```text
eat()
drink()
sleep()
work()
idle()
```

V1.0 **tidak memberikan seluruh skill sejak awal**.

Dengan demikian:

$$  
A_0={eat,drink,sleep,work,idle}  
$$

dan action space dapat berkembang:

$$
A_{t+1}=A_t\cup A_{new}  
$$

---

# 6. Experience

Experience tetap menggunakan representasi V0.5:

$$  
E_t=(S_t,A_t,S_{t+1})  
$$

dan:

$$
\Delta S=S_{t+1}-S_t  
$$

LR yang diperoleh dari experience menjadi dasar bagi skill acquisition.

Contoh:

```text
pick_up(raw_meat)
→ holding(raw_meat)

use_fire()
→ cooked_meat
```

Jika rangkaian tersebut secara konsisten menghasilkan:

```text
raw_meat → cooked_meat
```

maka rangkaian dapat menjadi kandidat skill.

---

# 7. Skill Discovery

V1.0 memperkenalkan proses:

$$  
Experience  
\rightarrow  
Candidate\ Sequence  
$$

Misalnya agent menemukan:

```text
A1 → A2
A1 → A2
A1 → A2
```

dengan konsekuensi yang konsisten.

Sistem kemudian membentuk:

```text
Candidate Skill:

A1 + A2
→ Effect E
```

Contoh:

```text
pick_up(raw_meat)
+
use_fire()
→
cooked_meat
```

menjadi:

```text
candidate:
cook(raw_meat)
```

---

# 8. Skill Representation

Skill tidak hanya disimpan sebagai sequence.

Representasi konseptual:

```text
Skill
├── Name
├── Preconditions
├── Action Sequence
├── Expected Effect
├── Success Condition
├── Failure Condition
└── Confidence
```

Contoh:

```text
cook(raw_meat)

Precondition:
raw_meat available
fire available

Sequence:
pick_up(raw_meat)
use_fire()

Expected Effect:
raw_meat → cooked_meat

Confidence:
should
```

Dengan demikian skill merupakan **abstraksi dari pengalaman**, bukan sekadar macro command.

---

# 9. Skill Validation

Kandidat skill tidak langsung dianggap valid.

Siklusnya:

```text
Candidate
    ↓
Execute
    ↓
Observe Result
    ↓
Success?
   / \
 No  Yes
 |     |
reject update evidence
          ↓
      repeat test
          ↓
      confidence
          ↓
      register
```

Satu keberhasilan tidak cukup untuk membuat action baru.

Skill harus menunjukkan konsistensi berdasarkan beberapa eksekusi.

# 10. Dynamic Action Registry

Pada awal:

```json
{
  "eat": {},
  "drink": {},
  "sleep": {},
  "work": {},
  "idle": {}
}
```

Setelah skill berhasil dipelajari:

```json
{
  "eat": {},
  "drink": {},
  "sleep": {},
  "work": {},
  "idle": {},
  "cook": {
    "type": "learned_skill",
    "sequence": [
      "pick_up",
      "use_fire"
    ],
    "effect": "cooked_meat"
  }
}
```

Dengan demikian `cook()` sekarang menjadi bagian dari action space.

---

# 11. Persistence

Skill baru disimpan pada Knowledge Layer.

```text
Trial 1
   ↓
Discover cook()
   ↓
Validate
   ↓
Register
   ↓
Persist
   ↓
Entity Core restart
   ↓
Load Action Registry
   ↓
cook() masih tersedia
```

Jadi persistence V1.0 mencakup:

```text
Learned Relations
+
Learned Skills
+
Action Registry
```

---

# 12. Contoh Skenario

Environment awal:

```text
Agent
Hunger = HIGH

Available:
raw_meat
fire
```

Action awal:

```text
eat()
drink()
sleep()
work()
idle()
```

Agent mencoba:

```text
eat(raw_meat)
```

→ gagal karena raw meat belum dapat dikonsumsi.

Agent memperoleh experience.

Kemudian mencoba sequence lain:

```text
pick_up(raw_meat)
use_fire()
```

dan memperoleh:

```text
raw_meat → cooked_meat
```

Setelah beberapa keberhasilan:

```text
Candidate Skill
      ↓
cook(raw_meat)
      ↓
validated
      ↓
Action Registry
```

Sekarang:

```text
cook(raw_meat)
```

menjadi action baru yang dapat digunakan pada decision cycle berikutnya.

# 13. Learning Loop V1.0

```text
Observe State
      ↓
Retrieve Knowledge
      ↓
Decision
      ↓
Execute Action
      ↓
Observe Consequence
      ↓
Generate Experience
      ↓
Update LR
      ↓
Detect Repeated Action Pattern
      ↓
Generate Candidate Skill
      ↓
Validate Candidate
      ↓
Register New Action
      ↓
Persist
      ↓
Repeat
```

Jadi terdapat **dua level learning**:

```text
Level 1
Experience
    ↓
Learned Relation


Level 2
Repeated Relations / Action Sequences
    ↓
Skill
    ↓
New Action
```

# 14. Eksperimen

V1.0 dapat membandingkan:

### Baseline

Agent hanya memiliki primitive action.

```text
A0 = primitive actions
```

### Dynamic Skill Agent

Agent dapat memperoleh action baru:

```text
A0
 ↓
learn
 ↓
A1 = A0 + learned skills
 ↓
learn again
 ↓
A2 = A1 + learned skills
```

Skenario environment dibuat sehingga task tertentu **tidak dapat diselesaikan menggunakan primitive action saja**, tetapi dapat diselesaikan setelah skill tertentu ditemukan.

---

# 15. Metrik

### M1 — Skill Acquisition Rate

$$
SAR=  
\frac{\text{validated skills}}  
{\text{candidate skills}}  
$$

### M2 — Time/Experience to Skill

Jumlah experience sampai skill berhasil diperoleh:

$$ 
N_{skill}  
$$

### M3 — Task Completion

Apakah task yang sebelumnya tidak dapat diselesaikan menjadi dapat diselesaikan setelah skill acquisition.

### M4 — Skill Retention

Setelah restart:

$$  
R_{skill}=  
\frac{\text{available learned skills after restart}}  
{\text{learned skills before restart}}  
$$

### M5 — Skill Reuse

Berapa kali skill yang diperoleh digunakan kembali pada kondisi berikutnya.

```text
      ↓

      ↓

      ↓

V1.0
────────────────────────

      ↓

      ↓
Detect action pattern
      ↓

      ↓

      ↓

      ↓

```

Jadi V1.0 merupakan **perluasan kemampuan belajar**, bukan sekadar menambahkan lebih banyak action secara hard-code.

---

# 17. Batasan V1.0

V1.0 masih belum mencakup:

- LLM sebagai mentor;
    
- open-ended skill invention tanpa batas;
    
- self-modifying source code;
    
- self-reproduction;
    
- evolutionary population;
    
- unrestricted Linux command execution;
    
- human-level planning.
    

Skill masih dibatasi oleh **primitive action dan observasi yang tersedia dalam environment**.

Ini penting: agent tidak benar-benar menciptakan kemampuan dari “nothing”. Ia **mengkomposisikan kemampuan dasar menjadi kemampuan yang lebih tinggi**.

---

# 18. Kontribusi yang Diharapkan

V1.0 diharapkan menghasilkan:

1. mekanisme _skill discovery_ berbasis experience;
    
2. mekanisme validasi skill sebelum menjadi action;
    
3. dynamic Action Registry;
    
4. persistent storage untuk skill yang diperoleh;
    
5. demonstrasi bahwa learned relational knowledge dapat digunakan sebagai dasar pembentukan skill baru;
    
6. evaluasi kemampuan agent untuk memperluas action space secara mandiri.
    

---

# 19. Inti V1.0

Secara keseluruhan, V1.0 memperluas loop V0.5:

$$
Experience  
\rightarrow  
LR  
\rightarrow  
Knowledge  
$$

menjadi:

$$ 
\boxed{  
Experience  
\rightarrow  
LR  
\rightarrow  
Skill\ Discovery  
\rightarrow  
Skill\ Validation  
\rightarrow  
New\ Action  
\rightarrow  
Persistent\ Knowledge  
}  
$$

Dengan kata lain:

> **V0.5 menguji apakah agen dapat belajar dan mempertahankan pengetahuan tentang konsekuensi tindakannya. V1.0 menguji apakah pengetahuan tersebut dapat digunakan untuk memperoleh kemampuan tindakan baru yang kemudian dapat dipertahankan dan digunakan kembali.**
